# Reverso de las cartas de la tienda

`card-back.png` es la imagen que Leo proporcionó el 8 de octubre de 2026 para el reverso de las cartas boca abajo de la tienda, dibujada ya a la proporción de la carta (0.686). Se conserva sin modificar. No se indicó autor ni licencia; no se le atribuye la licencia de código del repositorio.

`web/card-back.webp` es la copia que importa la tienda, generada con el mismo criterio que las [copias para pantalla del pase](../pass-skins/README.md#copias-para-pantalla), sin cambiar el tamaño porque el original no supera los 1200 px de ancho.
