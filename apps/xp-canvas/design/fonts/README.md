# Fuentes

Geist y Geist Mono, las mismas familias de leosan.xyz. Son copias sin modificar de las variables `Geist-Variable.woff2` y `GeistMono-Variable.woff2` del paquete `geist` 1.3.1 de Vercel, que usa el sitio personal. Se copian porque el paquete no permite importar sus archivos de fuente fuera de Next.

Su licencia es la SIL Open Font License 1.1, incluida en `LICENSE.TXT`, que permite incluirlas en la web. Se declaran en `client/index.css`. Geist Mono solo se usa en las fichas del logo y en la matrícula.
