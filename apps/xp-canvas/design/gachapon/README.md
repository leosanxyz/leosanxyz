# Tarjetas del gachapon

Seis imágenes proporcionadas por Leo para las recompensas del canvas. Se conservan los archivos originales sin modificar. Los nombres del catálogo describen las ilustraciones. No se proporcionaron autores ni licencias; no se atribuye a estas imágenes una licencia de código del repositorio.

Magia lunar utiliza la versión panorámica proporcionada por Leo. La tarjeta recorta la imagen con CSS y centra el encuadre en el personaje; el WebP original se conserva sin modificar.

El set 2 añade nueve imágenes proporcionadas por Leo: Fogata de Hyrule, Tracer, Soraka, Guerrero sombrío, Luke, Titán de ataque, Rengoku, Gyro Zeppeli y Emilia. Los archivos también se conservan sin modificar. El catálogo define el encuadre de cada tarjeta; `rewardHologramSubjects.ts` define las siluetas para aplicar el holograma al personaje o al fondo. No se proporcionaron autores ni licencias para estas nueve imágenes.
