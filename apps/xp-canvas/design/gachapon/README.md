# Tarjetas del gachapon

Seis imágenes proporcionadas por Leo para las recompensas del canvas. Se conservan los archivos originales sin modificar. Los nombres del catálogo son los de los personajes o juegos retratados: el Sinluz de Elden Ring, Ahri, Red Dead Redemption 2, Ranni, Malenia y Madoka y Homura. No se proporcionaron autores ni licencias; no se atribuye a estas imágenes una licencia de código del repositorio.

Ahri utiliza la versión panorámica proporcionada por Leo. La tarjeta recorta la imagen con CSS y centra el encuadre en el personaje; el WebP original se conserva sin modificar.

El set 2 añade nueve imágenes proporcionadas por Leo: Link, Tracer, Soraka, Yasuo, Luke, Eren, Rengoku, Gyro Zeppeli y Emilia. Los archivos también se conservan sin modificar. El catálogo define el encuadre de cada tarjeta; `rewardHologramSubjects.ts` define las siluetas para aplicar el holograma al personaje o al fondo. No se proporcionaron autores ni licencias para estas nueve imágenes.

Las ilustraciones de más de 300 KB tienen una copia WebP en `web/`, que es la que importa el catálogo. Se generan con el mismo criterio que las [portadas del pase](../pass-skins/README.md#copias-para-pantalla).
